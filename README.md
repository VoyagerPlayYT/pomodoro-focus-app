## 🌟 Описание проекта

**Smart Study & Pomodoro Focus App** — это научно обоснованный инструмент для борьбы с прокрастинацией и повышения эффективности подготовки к экзаменам, программирования и интервальных тренировок.

### Ключевые возможности:
- ⏱ **Гибкие режимы таймера**:
  - 🧠 «Учёба / Глубокий фокус» (25 минут)
  - ☕ «Короткий отдых» (5 минут)
  - 🌴 «Большая перезагрузка» (15 минут)
  - ⚡ Экспресс-тест (1 минута)
- 🌧 **Встроенный процедурный генератор шума дождя (Ambient Noise)**: синтезирует успокаивающий розово-броуновский шум напрямую через Web Audio API процессора звуковой карты без загрузки внешних MP3-файлов.
- 🔔 **Гармоничный сигнал завершения**: процедурный колокол (частота 528 Гц) мягко оповещает об окончании интервала.
- 📊 **Недельная аналитика продуктивности (Chart.js)**: наглядный график по дням недели (Пн–Вс), учет непрерывных серий (Streak) и общее количество часов чистой концентрации.
- 🎯 **Интегрированный список учебных целей** с расчетом помидорных интервалов (🍅 2/2).

## 🛠 Стек технологий

- **Backend**: Python 3.11+, FastAPI, Uvicorn, SQLite3
- **Frontend**: HTML5, Tailwind CSS в эстетике минимализма Zen Dark, Chart.js, динамические SVG-круги с аппаратным сглаживанием
- **Аудиодвижок**: Procedural Web Audio API Synthesizer (BiquadFilter, AudioBuffer, GainNode)

## 🚀 Быстрый запуск

### Запуск в 1 клик (Windows):
Дважды щелкните по:
```bash
start.bat
```
*(Приложение откроется в браузере по адресу `http://localhost:8007`)*.

### Запуск вручную:
```bash
pip install -r requirements.txt
python -m uvicorn main:app --host 0.0.0.0 --port 8007
```

## 🖥 Зачем этому проекту нужен выделенный сервер 24/7?

Для систем долгосрочного саморазвития и привычек решающую роль играет централизованное хранилище:

1. **Непрерывный учет прогресса с любых устройств**:
   - Можно запустить таймер на компьютере за письменным столом, а в перерыве продолжить чтение с планшета на диване — статистика не сбрасывается и сохраняется в центральной базе сервера.
2. **Семейный трекер привычек и спорта**:
   - На сервере могут вести свои интервалы учебы или тренировок все члены семьи (родители для йоги/зарядки, дети для учебы), видя общую шкалу семейной продуктивности.
3. **Голосовые анонсы через домашнюю акустику**:
   - Сервер 24/7 при окончании учебного часа может мягко включить свет в комнате или воспроизвести приятный гонг на умной колонке: «Время сделать гимнастику для глаз!».
